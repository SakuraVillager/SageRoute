2. **41 条未映射旧地点待复核，38 条没有坐标。** 多数没有描述、来源及人物关联，大量城市级地点被统一设置为祠庙陵寝。常州有两条近似记录；西湖、杭州郡治、望湖楼、灵隐寺、风水洞等还有地理范围重复或可能重叠的旧记录，未直接合并不等价地点。
