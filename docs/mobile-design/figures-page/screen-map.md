# SageRoute 人物页 Screen Map

## Information Architecture

```text
人物页 S1
├── 全局搜索 S2（覆盖层，关闭后回 S1 原上下文）
├── 文章页 S3（层级详情，返回 S1）
└── 人物详情页 S4（层级详情，返回 S1）
```

| ID | Responsibility | Primary Action | Key States |
| --- | --- | --- | --- |
| S1 | 发现内容，分别浏览主题推送文章和人物目录。 | 打开文章或人物详情。 | 初始加载、目录独立加载/空/失败、展开。 |
| S2 | 搜索人物、文章和主题名，不改变目录上下文。 | 选择有类型标识的搜索结果。 | 查询中、结果、空结果、失败。 |
| S3 | 阅读当前文章，正文沿用现有形式。 | 阅读或返回人物页。 | 加载失败、重试、返回恢复。 |
| S4 | 浏览选中人物的内容与数据。 | 浏览或返回人物页。 | 加载失败、重试、返回恢复。 |

## State Rules

- `ST1/ST2`：人物页初始加载与失败。
- `ST3/ST5`：主题推送文章列表的加载与空/失败。
- `ST4/ST6`：人物朝代目录的加载与空/失败。
- `ST7/ST8/ST9`：搜索查询中、空结果与失败。
- `ST10`：文章或人物详情的加载失败。

目录状态只归属于各自目录；搜索覆盖层关闭后恢复 S1 的目录状态。完整交叉引用、恢复条件和验收信号以 `ux-architecture.json` 为准。
