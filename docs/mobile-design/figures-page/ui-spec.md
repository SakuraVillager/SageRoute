# SageRoute 人物页 UI Specification

> UX source: `ux-architecture.json`  
> Wireframe source: `wireframe.json`  
> Visual lock: `visual-direction.md`  
> Platform: iOS + Android

## Foundations

- `surface.primary`: 暖白内容面；`surface.directory`: `#D3D3D3`；`text.primary`: 深棕；`action.selected`: 酒红。
- 文章、推荐主题和人物资料使用摄影承载内容身份；图片缺失时使用中性占位并保留标题与对象类型。
- 标题可换行，目录行和筛选项不依赖截断传递关键状态；大字号时优先增加行高和滚动高度。
- 触控目标遵循 iOS 44 pt、Android 48 dp 的最低要求。

## Screen Contracts

### S1 人物页

视觉优先级：精选文章 → 主题推送文章 → 人物目录 → 搜索与底部导航。

主题推送文章区域用主题筛选控制，仅刷新自身；人物目录区域用朝代筛选控制，仅刷新自身。两个区域分别展示前七项和“显示更多”。各自加载时用局部圆形进度；空结果提供清除筛选；失败提供重试。搜索按钮进入 S2，不改变当前上下文。

### S2 全局搜索

顶部保留关闭动作与键盘避让输入框。结果按人物、文章、主题显示类型、标题和明确跳转目标；查询中、空结果和失败不使用摄影干扰读取。关闭、系统返回或取消后恢复 S1 的滚动、筛选与展开状态。

### S3 文章页

进入为左向层级转场，正文暂沿用现有形式。加载失败时保留文章身份、重试与返回动作；右向返回或系统返回均恢复 S1。

### S4 人物详情页

从人物目录或搜索人物结果进入。以人物身份和关联内容为首要阅读对象；失败时提供重试和返回 S1。具体资料结构后续定义，不在本次扩展范围内。

## Accessibility And Platform

- 所有进度、空结果、错误、已选筛选项和“显示更多”状态提供文字与读屏语义。
- iOS 使用系统导航栈与边缘返回；Android 使用系统返回/预测返回，二者均不丢失人物页上下文。
- Reduce Motion 下转场改为短淡入淡出；不以动画表示唯一结果。
