# SageRoute 人物页 Visual Direction

## Locked Direction

用户已从此前的三款 HTML 可交互预览中选择 `02 博物馆展签`。该预览是本次静态视觉证据；用户明确不需要额外 ImageGen 渲染。

视觉命题：像一张安静的馆藏展签，让旅行叙事的照片承担发现入口，目录与筛选承担高频检索，不用装饰取代内容关系。

- 主色：暖白内容面、深棕墨色文字、酒红作为选中和重点、`#D3D3D3` 作为目录分割与推荐主题模块背景。
- 字体：人物页标题和文章标题采用宋体/Georgia 风格展示字；操作、筛选、目录和状态使用高可读界面字体。
- 材质：圆角影像框、低饱和暖白纸面、轻量阴影；不使用渐变、玻璃拟态或营销式大卡片。
- 资产：横向摄影作为文章与推荐主题的主要内容资产；小型文章封面辅助识别。
- 动效：文章左向进入、右向返回；圆形进度用于加载；减少动态时改为淡入/淡出并保留状态文案。
- 克制规则：无额外装饰插画、无紫蓝渐变、无悬浮大口号；目录维持紧凑扫描密度。

## Screen Continuity

| Screen | Focal point | Continuity |
| --- | --- | --- |
| S1 人物页 | 精选文章照片与可扫描目录 | 摄影、暖白与酒红强调并存。 |
| S2 搜索 | 查询与明确对象类型的结果 | 弱化影像，强调输入、类型和恢复。 |
| S3 文章页 | 文章主标题与正文阅读 | 延续影像封面和纸面阅读感。 |
| S4 人物详情 | 人物身份与关联内容 | 延续展签式信息层级，不改变返回语义。 |

静态预览不证明文字缩放、对比度、真实手势冲突或数据加载行为；这些在原型与平台审查阶段验证。
