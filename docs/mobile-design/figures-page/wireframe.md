# SageRoute 人物页 Low-Fidelity Wireframe Contract

## Source Contract

- UX source: `ux-architecture.json` v0.1.0
- Product scope: 文章发现、独立目录筛选、全局搜索、详情往返与恢复。
- Visual boundary: 本文只定义区域和状态，不定义颜色、排版、图片或组件外观。

## Navigation Skeleton

```text
人物页 S1 → 文章页 S3 → 返回并恢复 S1
     ├→ 搜索覆盖层 S2 → 文章/人物详情，或关闭恢复 S1
     └→ 人物详情 S4 → 返回并恢复 S1
```

## Screen Contracts

### S1 人物页

用户问题：我可以从哪些文章、主题和人物线索继续探索？

1. 固定安全区、页面身份与搜索入口。
2. 可滚动的精选文章入口。
3. 可滚动的主题推送文章区域，包含主题筛选、七项截断、展开、局部加载/空/失败。
4. 可滚动的人物目录区域，包含朝代筛选、七项截断、展开、局部加载/空/失败。
5. 固定底部导航。

主题筛选仅更新第 3 区域；朝代筛选仅更新第 4 区域。两个区域的空结果、失败与重试各自就地显示。

### S2 全局搜索

固定关闭动作和键盘避让的输入区；结果区可滚动，按人物、文章、主题展示明确类型与跳转目标。查询中、无结果、失败是同一任务的状态，关闭后恢复 S1，不改变 S1 的筛选与滚动位置。

### S3 文章页与 S4 人物详情页

两者都使用固定安全区/返回动作和可滚动内容区。详情加载失败不是新页面，保留重试与返回人物页的恢复动作。文章正文和人物详情内容本阶段不改变。

## Flow And State Coverage

- `F1`：文章进入前保存上下文；左进右返；失败可重试或返回。
- `F2`：搜索覆盖层独立管理输入、结果、空结果与失败。
- `F3`：主题文章与人物朝代筛选独立，两个目录各自展开与恢复。
- `F4`：失效推送不进入空白详情，而是说明原因并恢复到人物页。

`ST1` 至 `ST10` 已全部覆盖，完整区域合同与验收信号见 `wireframe.json`。
